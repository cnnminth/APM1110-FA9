Part 1: Stochastic Independence

1.1 Description of the Random Variables

Two continuous random variables, X and Y, are generated using a bivariate normal model.

The variables are constructed as follows:

  • X follows a standard normal distribution.
  • Y is generated using X and an independent standard normal random variable.
  • The correlation between X and Y is set to 0.70.

Since the correlation is not zero, the variables are dependent.

rho <- 0.70

Z1 <- rnorm(n)
Z2 <- rnorm(n)

X1 <- Z1
Y1 <- rho * Z1 + sqrt(1 - rho^2) * Z2

correlation <- cor(X1, Y1)

correlation
## [1] 0.6948977

1.5 Factorization Criterion

Two random variables are independent if their joint probability density can be expressed as the product of their marginal probability densities.

For continuous random variables:

fX,Y(x, y) = fX(x) * fY(y)

The following code compares empirical joint probabilities with the products of empirical marginal probabilities.

# Create finite breakpoints based on the observed data
breaks_X <- seq(
  min(X1) - 0.001,
  max(X1) + 0.001,
  length.out = 6
)

breaks_Y <- seq(
  min(Y1) - 0.001,
  max(Y1) + 0.001,
  length.out = 6
)

# Divide X and Y into intervals
bin_X <- cut(X1, breaks = breaks_X, include.lowest = TRUE)
bin_Y <- cut(Y1, breaks = breaks_Y, include.lowest = TRUE)

# Calculate empirical joint probabilities
joint_table <- prop.table(table(bin_X, bin_Y))

# Calculate empirical marginal probabilities
marginal_X <- prop.table(table(bin_X))
marginal_Y <- prop.table(table(bin_Y))

# Calculate products of marginal probabilities
independent_table <- outer(
  as.numeric(marginal_X),
  as.numeric(marginal_Y)
)

# Compare the probabilities
comparison <- data.frame(
  Joint_Probability = as.vector(joint_table),
  Product_of_Marginals = as.vector(independent_table)
)

We can also compare the theoretical joint density with the product of the marginal densities at (0, 0).

joint_density <- dnorm2 <- function(x, y, rho) {
  1 / (2 * pi * sqrt(1 - rho^2)) *
    exp(
      -(x^2 - 2 * rho * x * y + y^2) /
        (2 * (1 - rho^2))
    )
}

joint_at_zero <- dnorm2(0, 0, rho)
product_at_zero <- dnorm(0) * dnorm(0)

data.frame(
  Joint_Density = joint_at_zero,
  Product_of_Marginal_Densities = product_at_zero
)
##   Joint_Density Product_of_Marginal_Densities
## 1     0.2228615                     0.1591549

The joint density is not equal to the product of the marginal densities. This supports the conclusion that X and Y are dependent.

1.6 Conclusion for Part 1

The two random variables are dependent because they have a positive correlation of approximately 0.70. Their joint distribution does not factor into the product of their marginal distributions. Therefore, X and Y are not stochastically independent.

Part 2: Sums of Independent Random Variables

2.1 Description of the Random Variables

Let X and Y be independent Poisson random variables:

  • X follows a Poisson distribution with parameter lambda = 4.
  • Y follows a Poisson distribution with parameter lambda = 6.

The sum of two independent Poisson random variables also follows a Poisson distribution.

Therefore:

S = X + Y

S follows a Poisson distribution with parameter lambda = 10.

2.2 Generate Independent Observations

At least 5,000 observations are required. This simulation generates 10,000 observations from each distribution.

n2 <- 10000

X2 <- rpois(n2, lambda = 4)
Y2 <- rpois(n2, lambda = 6)

S <- X2 + Y2

head(data.frame(X2, Y2, S))
##   X2 Y2  S
## 1  5 12 17
## 2  2  9 11
## 3  5  6 11
## 4  5  4  9
## 5  8  8 16
## 6  3 10 13

2.3 Theoretical and Simulated Mean

For a Poisson random variable, the theoretical mean is equal to its parameter.

Therefore:

E(S) = 4 + 6 = 10

theoretical_mean <- 4 + 6
simulated_mean <- mean(S)

mean_comparison <- data.frame(
  Theoretical_Mean = theoretical_mean,
  Simulated_Mean = simulated_mean
)

mean_comparison
##   Theoretical_Mean Simulated_Mean
## 1               10         9.9991

2.4 Theoretical and Simulated Variance

For a Poisson random variable, the variance is also equal to its parameter.

Therefore:

Var(S) = 4 + 6 = 10

theoretical_variance <- 4 + 6
simulated_variance <- var(S)

variance_comparison <- data.frame(
  Theoretical_Variance = theoretical_variance,
  Simulated_Variance = simulated_variance
)

variance_comparison
##   Theoretical_Variance Simulated_Variance
## 1                   10            10.0093

2.5 Graphical Representation

hist(

)

2.6 Conclusion for Part 2

The sum of two independent Poisson random variables follows another Poisson distribution. The theoretical mean and variance are both equal to 10. The simulated values are expected to be close to the theoretical values because the simulation uses 10,000 observations.

Part 3: Conditional Distributions – Discrete Case

3.1 Description of the Random Variables

This part uses two discrete random variables:

  • X represents a student’s performance category: Low, Medium, or High.
  • Y represents the type of study method: Method A or Method B.

The conditional probabilities are defined as follows:

Performance Method A Method B
Low 0.60 0.20
Medium 0.30 0.30
High 0.10 0.50

Both study methods have an equal probability of being selected.

3.2 Generate Discrete Data

n3 <- 10000

Y3 <- sample(
  c("Method A", "Method B"),
  size = n3,
  replace = TRUE,
  prob = c(0.5, 0.5)
)

X3 <- character(n3)

for (i in 1:n3) {
  if (Y3[i] == "Method A") {
    X3[i] <- sample(
      c("Low", "Medium", "High"),
      size = 1,
      prob = c(0.60, 0.30, 0.10)
    )
  } else {
    X3[i] <- sample(
      c("Low", "Medium", "High"),
      size = 1,
      prob = c(0.20, 0.30, 0.50)
    )
  }
}

X3 <- factor(X3, levels = c("Low", "Medium", "High"))
Y3 <- factor(Y3, levels = c("Method A", "Method B"))

Part 4: Conditional Distributions – Continuous Case

4.1 Description of the Random Variables

Two continuous random variables are generated:

  • X follows a standard normal distribution.
  • Y is generated using X and an independent normal error term.

The relationship is defined as:

Y = 0.8X + error

The error term follows a normal distribution with mean 0 and standard deviation 0.6.

4.2 Generate Continuous Data

4.5 Empirical Conditional Distribution

To examine the conditional distribution of X given Y, we select observations where Y falls between its 60th and 70th percentiles.

  Y4 >= lower_Y & Y4 <= upper_Y
]

4.7 Interpretation

The conditional distribution represents the distribution of X among observations where Y falls within the selected interval. It differs from the overall marginal distribution of X because X and Y are positively related.

The conditional density function is:

fX|Y(x|y) = fX,Y(x,y) / fY(y)

This means that the conditional density is obtained by dividing the joint density by the marginal density of Y, provided that the marginal density is positive.

4.8 Conclusion for Part 4

The simulation demonstrates how the conditional distribution of one continuous random variable can be studied by selecting observations within a specific interval of another variable. The conditional distribution differs from the overall marginal distribution because X and Y are related.
